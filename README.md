# Hello World + Alpine Prime App

This app prints a "Hello, world!" message and then runs an **Alpine Linux Docker container** that executes a short Python script to return a 3-digit prime number.

## Requirements

- Docker
- Python 3.8+

## Run

```bash
python3 app.py
```

Example output:

```text
Hello, world!
3-digit prime from Alpine container: 101
```
